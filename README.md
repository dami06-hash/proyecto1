# Análisis del Rendimiento Académico de Estudiantes

Este proyecto realiza un análisis exploratorio de datos sobre las calificaciones finales de los estudiantes para identificar patrones y factores clave en su desempeño escolar.

## Dataset
* **Nombre:** Students Performance in Exams
* **Fuente:** Kaggle
* **Descripción breve:** Registro de 1,000 estudiantes que incluye puntajes en matemáticas, lectura y escritura, junto con datos demográficos, socioeconómicos y de preparación.

## Objetivo
Analizar cómo influyen factores socioeconómicos (nivel educativo de los padres, tipo de almuerzo) y el curso de preparación previo en el rendimiento académico general de los alumnos.

## Requisitos
Se requiere Python 3.x y las dependencias indicadas en el archivo `requirements.txt` (`pandas`, `matplotlib`, `seaborn`).
